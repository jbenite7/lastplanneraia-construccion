# Facts — Shell, Layout & Design System Unificado

1. El alcance está estrictamente limitado a vistas **desktop (viewport canónico 1180×820 px)** en **Dark Mode**.
2. Los 11 módulos a migrar con Sidebar Shell son: Programa General, Prog. Semanal, Actualizar Cronograma, Profesionales, Subcontratistas, Control de Cambios, Familias de Actividades, Paquetes/Contratos, PDC (`/pdc`), Indicadores y Torre de Control.
3. El entrypoint CSS `public/css/aia-design-system.css` se segmenta en núcleo ligero y adjuntos por vendor controlados por `foundation-shell.json`.
4. Los sub-goals `sidebar-todos-modulos`, `cierre-dark-mode-y-tablas`, `dark-mode-todos-los-modulos`, `segmentacion-entrypoint-css` y `design-system-nucleo-gobernanza` quedan absorbidos por este goal maestro.
