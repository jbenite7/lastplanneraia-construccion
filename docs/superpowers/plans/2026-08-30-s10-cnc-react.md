**Goal:** migrate `/programacion-semanal/cnc` from VIEW-37, DataTables and shared global JavaScript
to a native React CNC surface with server-authoritative project/week/actions, an operationally
repairable population, independent priority/diagnosis, read-only quantity evidence, area-aware
catalogs, filters/counts, responsive table/cards and individual classification editing, without
changing the BI KPI, RLS, schema or live data during verification.

**Architecture:** T01 supplies shell/session/project/week/theme/navigation; S08 supplies weekly row
identity, quantitative semantics and the event that requires CNC; S09 supplies the shared causal
catalog behavior. S10 adds one scoped CNC adapter, pure population/quantity/priority/diagnosis/action
policies and one narrow mutation behind exactly three endpoints. React validates every wire shape
with Zod, keeps one normalized row store and renders semantic table at 768+ and native cards below
768. VIEW-37 remains for pilot rollback until functional, RBAC, responsive, accessibility and
explicit visual gates pass; S11/CIC assets remain intact.

**Tech Stack:** PHP 8.3 in Docker Compose, React 19, TypeScript 7, react-router-dom 7, Vite 8, Zod 4,
Vitest 4, Testing Library, Playwright 1.61, Axe and AIA design-system tokens.

## Exact Contracts to Implement

### Server scope

```php
final readonly class CncScope
{
    public function __construct(
        public int $projectId,
        public int $week,
        public string $area,
        public int $maxWeek,
        public bool $confirmed,
    ) {}
}
```

Construct it from authenticated server context. Request payload/query must not populate any field.

### Population predicate

The database store may read a safe explicit candidate superset; `CncPopulationResolver` makes the
canonical decision. Equivalent logical predicate:

```text
same project/week
AND Activa in {1, "1", "NA"}
AND Es_TNP != 1
AND (
  comparable commitment > 0
  AND comparable real exists
  AND real + 0.0001 < commitment
  OR trim(category/cause/observation) has any content
)
```

Parenthesize SQL explicitly if it performs the predicate. Tests must show that the OR cannot escape
`project_id`, week, active universe or TNP exclusion. Prefer selecting the scoped candidate superset
and applying the pure resolver if SQL coercion would diverge from PHP normalization.

### Wire unions

```ts
type ClasificacionCncEntrada =
  | { mode: 'catalog'; causeId: number }
  | { mode: 'other'; categoryKey: string }
  | { mode: 'keep-current' };

type GuardarActividadCnc = {
  rowId: number;
  version: string;
  classification: ClasificacionCncEntrada;
  observations: string;
};
```

These are explanatory shapes only. Export actual types through `z.infer`, not handwritten
interfaces. Request has no week/project/area/db/role, quantities or free category/cause.

### Gateway

```ts
obtenerContextoCnc(signal?: AbortSignal): Promise<ContextoCnc>;
listarActividadesCnc(signal?: AbortSignal): Promise<ListaCnc>;
guardarActividadCnc(
  entrada: GuardarActividadCnc,
  csrfToken: string,
  signal?: AbortSignal,
): Promise<ResultadoGuardarCnc>;
```

Exact routes are `/api/cnc/context`, `/api/cnc/activities` and `/api/cnc/activity`. Mutation uses
`Content-Type: application/json` and `X-CSRF-Token`. No method accepts a server-context argument.
