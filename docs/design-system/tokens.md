# Tokens

Los tokens canonicos tienen dos capas:

- `--aia-*`: paleta y decisiones heredadas de marca.
- `--ds-*`: alias semanticos para componentes y gates nuevos.

## Tipografia

- `--ds-font-display`: Montserrat para titulos, metricas y jerarquia.
- `--ds-font-body`: Inter para cuerpo, tablas, formularios y navegacion.

## Color

- `--ds-color-brand-primary`: accion principal corporativa.
- `--ds-color-brand-construction`: acciones o contexto de obra.
- `--ds-color-bg-page`, `--ds-color-bg-canvas`, `--ds-color-bg-parchment`: fondos.
- `--ds-color-surface`, `--ds-color-surface-raised`, `--ds-color-surface-glass`: superficies.
- `--ds-color-state-*`: estados informativos, correctos, advertencias y criticos.

## Forma y profundidad

- Radios: `--ds-radius-xs` a `--ds-radius-2xl`, mas `--ds-radius-pill`.
- Sombras: `--ds-shadow-xs` a `--ds-shadow-xl`.
- Glass: `--ds-blur-glass`.

## Interaccion

- `--ds-target-min`: minimo tactil de 44px.
- `--ds-shadow-focus`: foco visible.
- `--ds-motion-fast` y `--ds-motion-standard`: movimiento sobrio.
